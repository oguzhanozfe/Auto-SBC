Private hosted solver

HTTPS only, without a path or custom port. Use a server you control; this beta is for one owner.

Enter the token configured on your server, not an EA password. It stays in this extension’s local storage and is never included in solve exports. Re-enter it when saving hosted settings.

The hosted beta accepts owned cards, up to 30 seconds and 5,000 input cards; chemistry requests have a smaller server limit. Priced concepts require the local server. Free hosts may sleep or restart and lose an in-memory job.

Stop any queue before changing settings. After saving, reload the EA tab, confirm the displayed destination and select Check server. An already-sent request may still finish.
