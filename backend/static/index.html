GET STARTED

Set up the browser companion.

Use Auto-SBC Studio with the EA FC Web App in Chrome.

1

Keep Studio running

Keep the local Studio service open while you use the browser companion. Check the connection status and refresh prices in the player catalog.

2

Install the companion

Download and extract the Chrome extension. Open chrome://extensions, enable Developer mode, then choose Load unpacked and select Auto-SBC-Chrome. Keep only one version enabled.

Download Chrome extension ↓
Prefer a userscript?

Install with Tampermonkey instead of the extension.

Download userscript ↓
3

Choose how to run

Open Auto-SBC in the EA Web App. Review and apply a single squad, or approve a selected batch or daily plan for automatic completion.

Open EA Web App →

FC 26 has been tested in the EA Web App with Paletools locks. FC 27 live compatibility has not been verified. The browser companion does not run inside the native iOS or Android Companion apps.
