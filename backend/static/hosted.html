Your private solver endpoint

This single-owner service is used through the Auto-SBC Chrome extension. The interactive Studio dashboard is available in local mode. This page does not load club data or accept an access token.

Connect the extension

  1. Install the reviewed Auto-SBC Chrome extension and copy its extension ID from chrome://extensions into this server’s AUTOSBC_EXTENSION_IDS configuration.
  2. Open the extension’s server settings and choose My private HTTPS server. Enter this service’s exact HTTPS origin and its owner access token. Keep the token private; do not place it in a URL.
  3. Review and approve sending your SBC requirements and club-card data to that destination. Reload the EA Web App, confirm the displayed server, then select Check server.

Evaluation limits

This initial hosted profile accepts owned cards, one solve at a time, with up to 5,000 input cards and a 30-second solver budget. Chemistry requests have a separate server-configured limit, initially 200 cards. Oversized requests are rejected without removing candidates. Concepts require local Studio in this release.

Free hosting may sleep or restart. If the initial connection times out during a cold start, wait and check the server again. A lost solve job requires a fresh review; account actions are never replayed automatically.

Jobs, catalog data, downloads and diagnostics require the owner token. Public health contains only the service status, version and mode. Review how data is handled before connecting your club.
