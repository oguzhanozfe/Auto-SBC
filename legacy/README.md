# Archived original diagnostics

These scripts are preserved from the previous fork for contribution history.
They assume old local CSV files, use older EA/FUT.GG interfaces, or attach test
hooks. They are not part of Auto-SBC Studio's supported startup or test flow.

Use `scripts/sync_catalog.py` for the public database, the top-level generated
userscript for browser installation, and `python -m pytest` for current tests.
The old Selenium scraper is not run or required by this project.
